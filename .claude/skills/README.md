# Skills del proyecto

Aquí solo van skills revisadas con la lista de comprobación de `docs/skills.md`.
Cada skill se copia en su propia carpeta (`.claude/skills/<nombre>/SKILL.md`) y se anota su commit de origen en `docs/skills.md`.
No se usan instaladores automáticos (`npx skills add`, `install.sh`).

Instaladas y su origen: ver la tabla "Instaladas" de `docs/skills.md`. Las skills de trailofbits/skills se distribuyen bajo CC-BY-SA-4.0 (© Trail of Bits); las de obra/superpowers y sveltejs/ai-tools, bajo MIT.
